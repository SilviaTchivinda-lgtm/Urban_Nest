# UrbanNest Retail: Sales Data Analyst

## Project Overview 

This project analysis UrbanNest sales data using Python, Pandas and PostgreSQL and Pgadmin 4.

The project focuses on organising the sales data into structured SQL tables and analysing orders, revenue, customers, products and delivery information.

## Dataset 

The data contains 1,000 sales records with information including:

- Customer information
- Order information
- Product information
- Order revenue
- Payment method
- Sales channel
- Order status
- Delivery status
- Customer ratings
- Return information

## Tools Used

* Python
* Pandas
* Jupyter
* Github
* PgAdmin 4
* PostgreSQL

## Database Tables 

The data was organised into the following tables:
* Costumers
* Products
* Orders
* Order_items
* Deliveries

## Analysis 

The Project includes calculation for 
* Total revenue
* Total number of order
* Revenue by product
* Revenue by sales channel
* Delivery performance

## Project Objectives 

The main objectives are to:

1. Tack Business Sales:
   * Customer Purchasing Behavior
   * Product Performance
   * Revenue and order fulfilment

2. Organise the data:
   * Store the sales data in PostgreSQL
   * Organise the data into structured tables
   * Maintain the original dataset
   * Calculate important sales metrics
   * Use SQL queries to support business analysis
